# n8n_criar_workflow
Instala os 3 workflows padrao HOK OS no N8N via script Python.

## Quando usar
- Usuario quer instalar os 3 workflows padrao HOK OS
- Implantar monitor saude, backup sqlite ou alerta ram

## Prompts que ativam esta skill
- "crie os workflows no n8n"
- "implantar workflows n8n"
- "instalar automacoes padrao n8n"
- "monitor saude backup sqlite alerta ram"
- "ativar workflows hokma"
- "criar os 3 workflows de monitoramento"

## Acao

```bash
python3 /root/hokma/backend/scripts/n8n_create_workflows.py
```
