## Causa raiz encontrada

### Sintoma 1 e 2: nginx não fazia proxy para `/session/*` e `/models/*`

A configuração do nginx (`/etc/nginx/sites-enabled/hokma-web`, linha 17) tinha uma regex de proxy que NÃO incluía `session` ou `models`:

```nginx
location ~ ^/(chat|terminal|...|openrouter) {
```

Quando o frontend chamava `POST /session/mode`, o nginx retornava **405 Not Allowed** (POST para arquivo estático inexistente). O catálogo de modelos retornava SPA HTML em vez de JSON.

**Nota:** Este bug é **pré-existente** — a config do nginx não foi alterada pela sessão de 08/09 (modificação em 07/09). Tornou-se visível porque o frontend foi rebuildado hoje.

### Sintoma 3: Preview

O Preview estava funcionando (200 OK) — o sintoma pode ter sido temporário ou relacionado ao frontend.
